# Prathmesh Garud — Portfolio Website

A responsive, single-page portfolio built with HTML and CSS (no build tools required).

## Preview locally
1. Extract the ZIP.
2. Open `index.html` in a browser.

## Before publishing
- Replace the generic GitHub link in `index.html` with your exact GitHub profile URL.
- Verify the LinkedIn URL is the correct public profile.
- Review the education date and all resume details for accuracy.
- Add live project/GitHub links and project screenshots when available.
- Replace the resume PDF whenever you update your CV.

## Deploy
You can publish this static site using GitHub Pages, Netlify, or Vercel. Upload the extracted folder or connect its Git repository.
